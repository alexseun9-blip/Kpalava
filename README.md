# KPALAVA!

**Na you choose am!**

A mobile-first interactive Nigerian comedy story game prototype.

## Play locally
Open `index.html` in a modern browser.

## Current prototype
- Featured story: *The Wedding That Almost Didn't Happen*
- Chapter 1 branching choices and cliffhanger
- Demo coin display (not real purchases)
- Local browser storage for the demo coin balance

## Important
This is an early playable prototype. It does not yet include user accounts, cloud saves, secure coin purchases, an admin content system, or Chapter 2. The demo coin balance is not connected to payments.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the public site URL when deployment finishes.
